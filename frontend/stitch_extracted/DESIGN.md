## Brand & Style

This design system is tailored for an institutional-grade academic integrity and paper retraction risk intelligence engine. The aesthetic marries forensic data clarity with high-end computational rigor—evoking the authority of a peer-reviewed editorial board and the surgical precision of an advanced threat-detection console.

The style operates as an **Instrument-Grade Minimalist Glass** system. Rather than heavy, decorative glassmorphism, it deploys razor-sharp, hairline boundaries, sub-surface luminous accents, and controlled dark obsidian layering to structure dense evidentiary trees, citation networks, and probabilistic telemetry.

Key visual pillars:
- **Forensic Precision:** High-contrast metadata, structured scalar metrics, and disciplined monospaced readouts for identifiers (DOIs, PMIDs, ORCIDs).
- **Clinical Risk Signifiers:** Non-negotiable semantic risk hierarchy (Verified, Anomalous, Retracted/Critical) isolated strictly to functional status flags and confidence meters.
- **Controlled Density:** Maximized screen utility without cognitive collapse, relying on structural surface contrast rather than spatial bulk.

## Colors

The palette establishes an ultra-deep obsidian plane that minimizes optical fatigue during prolonged audit sessions while granting acute vibrance to integrity vectors and classification tags.

### Core Foundation
- **Canvas Base (`#0B0F19`):** Absolute canvas baseline; deep slate obsidian absorbing background distractions.
- **Card Layer 1 (`#111827`):** Primary structural surface for modules, table matrices, and dossier summary panes.
- **Card Layer 2 (`#1F2937`):** Elevated utility planes, hover states, input surfaces, and nested inspector drawers.
- **Hairline Border (`rgba(31, 41, 55, 0.8)` / `#1F2937`):** Architectural boundary definition that prevents visual bleed between panels.

### Brand Accents
- **Primary Indigo (`#6366F1`):** Action targets, selected filters, active analytics pathways, and authoritative platform branding.
- **Secondary Violet (`#818CF8`):** Focus rings, interactive hover states, multi-variable line graphs, and cross-reference links.

### Diagnostic Risk Tiers
- **Clean / Verified (`#10B981`):** Clean replication logs, verified methodology, no image or text duplication.
- **Anomalous / Warning (`#F59E0B`):** Borderline metrics, unverified citations, peer-review concerns, moderate statistical drifts.
- **High Risk / Retraction Candidate (`#EF4444` / `#F43F5E`):** Severe ethical breaches, fabrication alerts, flagged figures, confirmed retraction notices.

## Typography

The typographic hierarchy prioritizes rapid scanning, academic legibility, and technical verification. 

- **Primary Matrix (Inter):** Serves headlines, executive syntheses, narrative reports, and standard structural navigation. Inter provides optical balance at tight body sizes while retaining neutral authority in dense administrative tables.
- **Telemetry & Identifier Layer (JetBrains Mono):** Reserved for technical tokens—DOIs, ISSNs, hash signatures, p-value calculations, sample size counters, confidence interval readouts, and severity chips. The fixed-width character grid guarantees zero horizontal shift across streaming analysis states or dynamic numerical tables.
- **Pacing & Casing:** System labels and semantic metrics utilize upper or capitalized monospace variants (`label-sm`, `label-md`) with expanded tracking to maximize legibility against dark substrates.

## Layout & Spacing

The layout model uses a responsive 12-column fluid grid calibrated for complex analytical dashboards, split-pane PDF auditors, and citation tree graphs.

### Structure & Rhythm
- **Desktop (>= 1280px):** 12-column grid, `gutter-desktop` (1.5rem), `margin-desktop` (2.5rem). Allows dynamic tri-pane layouts: Left Navigation/Batch Queue, Center Document Inspector, Right Risk Telemetry Bar.
- **Tablet (768px - 1279px):** 8-column layout, `gutter` (1rem), `margin-tablet` (1.5rem). Inspector panels collapse into tabbed side-drawers; summary indicators dock to sticky top cards.
- **Mobile (< 768px):** 4-column layout, `gutter` (1rem), `margin` (1rem). Dense metric tables convert into vertically stacked audit cards; non-essential continuous telemetry collapses into expandable accordions.

### Density Rules
Padding within analytic cards conforms to an 8px (0.5rem) baseline scale. Data tables enforce compact row heights (36px to 44px) paired with `space-sm` cell padding to sustain data density, while dossier overviews utilize `space-lg` to create clear reading breaks between analytical domains.

## Elevation & Depth

Visual hierarchy does not rely on diffused drop shadows, which muddy dark canvas contrast. Instead, depth is produced via **chromatic layering, hairline luminescence, and frosted backdrop dissipation**.

### Surface Elevation Hierarchy
- **Level 0 (Canvas Base - `#0B0F19`):** Ground plane for page framing, background space, and structural grid gutters.
- **Level 1 (Card & Module Shells - `#111827`):** Primary working plane. Surfaced with a 1px solid border (`#1F2937`). No box shadow; crisp edge clipping only.
- **Level 2 (Active Inspections & Hover Panels - `#182234`):** Activated cards, dropdown menus, and hovered grid cells. Elevated using an ultra-subtle directional gradient and a 1px border highlighted with `rgba(99, 102, 241, 0.25)`.
- **Level 3 (Diagnostic Drawers & Modals - `#111827` over Backdrop Blur):** Floating diagnostics, full audit logs, and PDF overlay tools. Utilizes `backdrop-filter: blur(12px)` over `rgba(11, 15, 25, 0.75)` canvas overlays, sealed with a 1px perimeter border of `#374151` and an ambient glow of `0 20px 40px rgba(0, 0, 0, 0.6)`.

### Risk Accent Illumination
Critical flags utilize a controlled edge-glow: an amber or crimson 1px hairline border paired with an inner box shadow (`inset 0 0 12px rgba(239, 68, 68, 0.08)`) to immediately signal high-risk alerts without disrupting the underlying dark canvas.

## Shapes

The geometric framework uses **Soft (`1`)** curvature. Surfaces favor technical, architectural edges that preserve screen space and project scientific precision:

- **Micro Components (Chips, Badges, Monospace Tags):** `rounded` (0.25rem) to preserve structural alignment alongside monospace strings.
- **Interactive Controls (Inputs, Buttons, Tabs):** `rounded` (0.25rem) to reinforce an instrument-grade workstation aesthetic.
- **Containers & Panels (Data Cards, Dossier Modules):** `rounded-lg` (0.5rem), providing a controlled, restrained frame.
- **Flyouts & Modals:** `rounded-xl` (0.75rem), offering gentle optical separation from the rigid grid below.

## Components

### Buttons & Interactive Controls
- **Primary:** Background `#6366F1`, text white, `rounded` (0.25rem), typography `Inter 14px 600`. Hover state transitions to `#818CF8`.
- **Secondary / Outline:** Background `transparent`, border 1px solid `#1F2937`, text `#D1D5DB`. Hover applies `#111827` surface and `#818CF8` border.
- **Destructive / Flag Risk:** Background `rgba(239, 68, 68, 0.1)`, border 1px solid `rgba(239, 68, 68, 0.4)`, text `#F87171`. Hover transitions to full `#EF4444` background with pure white text.

### Risk Status Chips
- Rendered exclusively using `JetBrains Mono` (`label-sm`).
- **Format:** High-contrast pill featuring a pulsating 6px status circle preceding the risk label.
  - *Clean:* `rgba(16, 185, 129, 0.1)` fill, `#10B981` border, `#34D399` text.
  - *Suspicious:* `rgba(245, 158, 11, 0.1)` fill, `#F59E0B` border, `#FBBF24` text.
  - *Critical Retraction Risk:* `rgba(239, 68, 68, 0.15)` fill, `#EF4444` border, `#FCA5A5` text.

### Input Fields & Search Bars
- Background `#111827`, inset hairline border 1px `#1F2937`.
- Text color `#F3F4F6`, placeholder `#6B7280`. Monospace typography applied whenever inputs accept DOIs, ArXiv IDs, or code sequences.
- Focus state triggers an immediate 1px border highlight `#6366F1` accompanied by a localized `0 0 0 2px rgba(99, 102, 241, 0.2)` ring.

### Data Tables & Evidence Lists
- Headers styled in `label-sm` (uppercase `JetBrains Mono`), color `#9CA3AF`, background `#0B0F19`.
- Rows use bottom borders of 1px `#1F2937` with alternating row highlighting optional via `rgba(255, 255, 255, 0.015)`.
- Numeric data, impact factors, p-values, and publication dates strictly align right using tabular figures.

### Analytics Cards & Inspector Tiles
- Background `#111827` with 1px hairline border `#1F2937`.
- Header row cleanly separates the metric category (`label-md` `#9CA3AF`) from status badges.
- Critical risk cards feature an accent top border: a 2px stroke in `#10B981`, `#F59E0B`, or `#EF4444` indicating category health at a glance.

### Checkboxes & Radio Selection
- 16px square/circle with `#111827` surface and 1px border `#374151`.
- Checked state fills `#6366F1` with an ultra-crisp white vector checkmark or dot indicator.

### Specialized Platform Components
- **DOI Pill Tag:** Specialized monospace tag featuring an interactive copy-to-clipboard trigger and a one-click lookup link.
- **Risk Distribution Histogram:** Segmented inline visual bar displaying Clean / Borderline / Retraction candidate ratios using the semantic risk palette.
